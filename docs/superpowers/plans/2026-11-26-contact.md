# Contact Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve `/contact` with the design's three-mode form, sending through a new route to sales@ and tjallen@ in production only, with nothing reaching them before cutover.

**Architecture:** `lib/site/contactForm.js` holds the form's copy, lists, validation and the lead email (shared by client and server). `app/api/site/contact/route.js` validates, honours the honeypot, sends via `applyEmailSafety()`, then (production only) HubSpot and (always) attribution. A client `ContactForm` handles modes, preselect, errors, sending, thank-you and the production-only mailto fallback. A server `ContactPage` lays out the design and passes `fallbackEmail` from `isProduction()`.

**Tech Stack:** Next.js 15 App Router (JSX), nodemailer, Jest (node env for the route, jsdom for components), Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-26-contact-design.md`

## Global Constraints

- Production recipients exactly `["sales@thetorontosaunaco.com", "tjallen@thetorontosaunaco.com"]`, set only in the route (server). Every send goes through `applyEmailSafety()`. Client fallback mailto: `sales@thetorontosaunaco.com` in production only, `null` otherwise. `tjallen@` never appears in client code.
- HubSpot only when `isProduction()`. Attribution saved with `formType: "site_contact"`.
- Copy verbatim from `content/redesign/Contact.json`; copy that exists only in the design script goes, verbatim from `Contact.dc.html`, into `CONTACT_COPY` in `lib/site/contactForm.js`.
- Every visitor value HTML-escaped in the email. Caps: 200 chars per field, 5000 for `msg`.
- New components in `components/site/`; `desktop:` breakpoint; tokens only; container `mx-auto max-w-site px-5 desktop:px-8`.
- No change to `/api/emails`, `components/Contact.jsx` or any live form. Never print `.env` values; tests never send real mail (nodemailer mocked).
- Tests beside the code. Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A non-production send must never carry a real team address in `to`/`cc`/`bcc`. (Task 2 test with `VERCEL_ENV=preview`)
2. `STAGING_EMAIL_TO` unset outside production: nothing sent, 500, and the form shows the call-us message with no mailto. (Task 2 + Task 3 tests)
3. Markup typed into any field arrives escaped in the email HTML. (Task 1 + Task 2 tests)
4. `/contact#visit` and `/contact?visit` open in visit mode; `#question` in question mode. (Task 3 test)
5. HubSpot or attribution failing after a successful send still answers 200. (Task 2 test)
